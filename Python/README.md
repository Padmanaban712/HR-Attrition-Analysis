
# Python Data Cleaning & Exploratory Data Analysis

## Overview
Python was used to explore and analyze the HR Analytics dataset as part of the end-to-end HR Attrition Analysis project.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Data Exploration
- Loaded the HR dataset using Pandas
- Inspected dataset structure and statistical summaries
- Checked data types and categorical values
- Identified missing values and duplicate records

## Exploratory Data Analysis
- Analyzed employee attrition distribution
- Calculated overall attrition percentage
- Examined attrition based on overtime
- Analyzed attrition based on job satisfaction

## Visualizations
- Employee Attrition Distribution
- Attrition Rate by Overtime
- Attrition Rate by Job Satisfaction

## Output
Exported the HR dataset to CSV format for further analysis using SQL and Power BI.

Python | Pandas | Data Exploration | EDA | Data Visualization
