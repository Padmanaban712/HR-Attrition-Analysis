
# HR Attrition Analysis | SQL

## Overview
SQL was used to analyze employee attrition and workforce trends as part of the end-to-end HR Attrition Analysis project.

## Tools Used
- Oracle SQL
- HR Analytics Dataset

## Business Questions
- What is the total number of employees?
- How many employees have left the organization?
- What is the overall attrition rate?
- Which departments have the highest employee count?
- Which job roles have the highest attrition?
- Does employee tenure differ between employees who stayed and left?
- Is monthly income associated with employee attrition?
- How do training, job satisfaction, and promotion patterns vary?

## SQL Concepts Used
- SELECT and WHERE
- Aggregate Functions
- GROUP BY and ORDER BY
- CASE WHEN
- Subqueries
- COUNT, AVG, ROUND

## Analysis Areas
- Workforce Distribution
- Employee Attrition
- Department and Job Role Analysis
- Employee Experience and Compensation
- Training and Performance
- Job Satisfaction and Career Development

## Skills Demonstrated
Oracle SQL | Data Analysis | Business Queries | HR Analytics
