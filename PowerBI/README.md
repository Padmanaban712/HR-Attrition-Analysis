
# HR Attrition Analysis Dashboard | Power BI

## Overview
An interactive HR Attrition Analysis dashboard developed using Power BI to understand employee attrition patterns and workforce trends.

## Tools Used
- Power BI
- Power Query
- DAX
- HR Analytics Dataset

## Dashboard Pages

### Page 1: HR Overview
- Total Employees
- Employees Left
- Attrition Rate
- Average Monthly Income
- Department-wise employee distribution
- Job role-wise attrition analysis

### Page 2: Attrition Analysis
- Attrition Rate by Overtime
- Attrition Rate by Job Satisfaction
- Attrition Rate by Work-Life Balance
- Attrition by Marital Status
- Employee Attrition Details

### Page 3: Workforce Insights
- Employees by Education
- Monthly Salary by Job Role
- Employees by Business Travel
- Employee Age Distribution
- Experience by Job Level
- Training and Workforce Insights

## Key Features
- Interactive dashboard pages
- KPI cards
- Department and employee filters
- Attrition trend analysis
- Workforce insights

## Skills Demonstrated
Power BI | DAX | Data Modeling | Data Visualization | Dashboard Development
